# 1.3.0 — Restore the `app:make` console command

## What changed

`app:make` is back, regenerating a full application from the `.sgf` templates
shipped inside the framework package.

- Added `Strukt\Framework\Console\Command\AppMake`.
- Added a template tree under `templates/app/` that mirrors the original
  `app:make` scaffold:
  - `src/{{app}}/AuthModule/{{app}}AuthModule.sgf` — the module class
    (`<App>AuthModule`, alias `au`).
  - `src/{{app}}/AuthModule/Controller/User.sgf`, `Form/User.sgf`,
    `Router/Index.sgf`, and `Tests/UserTest.sgf` — the four configured facet
    folders.
  - `src/{{app}}/User.sgf` — an `Entity` model.
  - `cfg/app.sgf` — the generated `cfg/app.ini` with the default middlewares
    and providers.
- The command camelises the app name, writes the rendered tree under
  `rel_appsrc` (so the `AuthModule` is picked up by `app:reload` and the
  `Registrar`), renders every path and file through `Strukt\Templator`, maps
  `.sgf` to `.php`, and refuses to overwrite an existing application.
- Registered `app:make` in `cfg/cmd.ini [main]` and in
  `Strukt\Package\Core::commands()`.

## Why

`app:make` was part of the strukt1 tooling that did not make it into the
remake. Scaffolding an application is the first step of every new project, and
restoring it gives `app:reload` and `module:make` something to operate on.

## Documentation

- `README.md`: added `app:make` to the console commands table.

## Tests

- Added `tests/Unit/AppMakeTest.php`: generation of the full tree under a
  temporary `root_dir`, rendering of the app name into sources and `cfg/app.ini`,
  rejection of an existing application, and camel-case conversion of underscored
  names.

## Public API impact

- New public class: `Strukt\Framework\Console\Command\AppMake` (implements
  `Strukt\Console\Runtime\CommandInterface`).
- New scaffolding templates: `templates/app/**` — the path segments `src/` and
  `{{app}}` are placeholders resolved by the command, so editing the tree
  customises what every new application is generated from.
