# 1.1.0 — SOLID refactor

Refactored the framework core to follow the SOLID principles more closely.

## What changed

### Dependency Inversion (D)

- Introduced the `Strukt\Framework\Contract\Kernel` port (route registration,
  middleware wiring, run/handle dispatch) so the application no longer depends
  on the concrete `Strukt\Router\Router`.
- Added `Strukt\Framework\Router\RouterAdapter` which wraps the concrete router
  and is the only place transport types (verbs, `Route`) are touched.
- `Application` now depends on `Kernel`, `Registrar`, and an optional
  `Configuration`. `Application::make()` is a convenience factory that wraps the
  shared router in the adapter.

### Single Responsibility (S)

- Extracted module/facet discovery out of `Application` into
  `Strukt\Framework\Module\Registrar` (owns module deduplication, the alias map,
  and the `nr.*` registry entries).
- Extracted provider/middleware wiring into `Strukt\Framework\Bootstrap`.
- `Application` is now an orchestrator that only sequences its collaborators.
- Split `Shell`: discovery and parsing moved to
  `Strukt\Framework\Console\CommandRepository`, and markdown rendering moved to
  `Strukt\Framework\Console\Documenter`. `Shell` now only dispatches.

### Open/Closed (O)

- HTTP verb routing moved into `RouterAdapter`; registering a new verb touches
  only the adapter.
- `Injectable\Validator`'s annotation-to-rule translation is now data-driven
  (`RULES` and `TOKENS` lookup tables) instead of a closed `match` expression.

## Why

- The original single-class `Application` mixed module discovery, bootstrap, and
  route registration; `Shell` mixed discovery, parsing, and documentation.
- Depending on the concrete router tied the kernel to a specific implementation
  and made the verb mapping swallowable only by editing the kernel.

## Documentation

- `README.md`: quick start and dispatch sections now use `Application::make()`.

## Tests

- Updated `tests/Unit/ApplicationTest.php` to construct the application through
  `Application::make()`; all discovery and route-registration assertions
  unchanged. Full suite (16 tests) and `composer lint` pass.

## Public API impact

- `new Application($router, $configuration)` constructor signature changed.
  Replacement: `Application::make($router, $configuration)`.
- `Application::init()` / `run()` / `handle()` / `register()` / `modules()`
  behavior is unchanged.
- `Shell` constructor and `run($argv)` are unchanged.
- New public classes: `Contract\Kernel`, `Router\RouterAdapter`,
  `Module\Registrar`, `Bootstrap`, `Console\CommandRepository`,
  `Console\Documenter`.
