# Ignore generated application artifacts

## What changed

Extended `.gitignore` so the artifacts the framework generates when it is
exercised as an application from its own root are not committed:

```
/composer.lock
/app/
/lib/
/index.php
/.env
/.cache/
/php_errors.log
/cfg/app.ini
```

`/vendor/` and the PHPUnit caches were already ignored.

## Why

Running `app:make`, `app:reload`, `app:exec`, `route:make`, `validator:make`,
or `cache:*` from the package root writes an application tree (`app/`, `lib/`,
`index.php`, `.env`, `cfg/app.ini`) and runtime output (`.cache/`,
`php_errors.log`) — the same set `strukt1/strukt-framework` ignored. None of it
belongs in the library. The shipped configuration is limited to
`cfg/cache.ini`, `cfg/cmd.ini`, `cfg/module.ini`, and `cfg/repo.ini`;
`cfg/app.ini` is written by `app:make`.
