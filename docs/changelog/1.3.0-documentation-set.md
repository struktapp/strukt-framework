# Reference documentation set

## What changed

- Added a `docs/` reference set: `README.md` (index), `architecture.md`,
  `getting-started.md`, `console.md`, `routing.md`, `forms-and-validation.md`,
  `dependency-injection.md`, `configuration.md`, `packages.md`,
  `extensions.md`, `annotations.md`, `helpers.md`, and `testing.md`.
- Linked the new documentation index from the package README.

## Why

The package shipped only a README and a changelog. The architecture —
the application orchestration, module registry, configuration discovery,
runtime autoloading, extendables, and console — had no written reference, which
made the port hard to navigate.

## Documentation

- New: all files listed above under `docs/`.
- Updated: `README.md` gained a `Documentation` section linking to `docs/`.
