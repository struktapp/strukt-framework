# Move the annotation parser into strukt/generator

## What changed

- Removed `Strukt\Framework\Annotation\Parser` (and the now-empty
  `src/Strukt/Framework/Annotation/` directory).
- The injectables now import `Strukt\Annotation\Parser` from `strukt/generator`:
  `Injectable\Router`, `Injectable\Validator`, `Injectable\Facet`, and
  `Injectable\Configuration`.
- Moved the parser test and its fixtures to `strukt/generator`; removed
  `tests/Unit/ParserTest.php`, `tests/Fixtures/Annotated.php`, and
  `tests/Fixtures/Tagged.php` from the framework suite.

## Why

The `Parser` only depends on PHP reflection and `strukt/generator` already
advertises PHPDoc annotation utilities. Co-locating it with the rest of the
generator/annotation code keeps the framework package focused on bootstrapping
and dependency injection, and lets other packages parse annotations without
pulling in the framework.

## Documentation

- None; the class docblock example is unchanged apart from the namespace.

## Tests

- `tests/Unit/ParserTest.php` moved to `strukt/generator`
  (`tests/Unit/ParserTest.php`) with inlined fixtures. Framework suite: 56
  passed; generator suite: 9 passed.

## Public API impact

- **Breaking:** `Strukt\Framework\Annotation\Parser` is now
  `Strukt\Annotation\Parser`, published by `strukt/generator` (already a
  framework dependency). Update any imports accordingly.
