# xhttp development tool

## What changed

- Added a development-only, in-process HTTP client, `xhttp`, as its own binary
  `bin/xhttp` published by Composer. It builds a request from the command line,
  boots the application, dispatches it through the application's own kernel, and
  prints the response — no web server required.
- Added `Strukt\Framework\Console\Xhttp` with `request()`, `run()`, `render()`,
  and a static `help()`. `run()` initializes the app on the current global
  router, then dispatches via `router()->kernel()->handle()`.
- `--session key=value` (repeatable) seeds the router session before dispatch, so
  routes behind the `sess`/`auth` middleware can be exercised without logging in.
- The binary is gated on `is_dev`: it refuses to run (exit `1`) unless `is_dev`
  is true. `--help` is always available.
- Added `"bin/xhttp"` to the `bin` list in `composer.json`.

## Why

Porting the strukt1 `xhttp` shell helper completes the developer tooling set for
strukt4 in a cleaner shape: as a standalone binary rather than per-application
scaffolding. Unlike the strukt1 helper it does not mutate `$_SERVER` or scrape
docblocks; it dispatches through the real kernel and prints the actual response.

## Documentation

- `docs/xhttp.md`: new reference page (usage, options, examples, session
  seeding, how it works, limitations, programmatic use).
- `docs/README.md`: `xhttp.md` added to the Guides table.
- `docs/console.md`: the binary section notes the `xhttp` sibling binary.
- `README.md`: the console quick-start mentions the `xhttp` binary.

## Tests

- `tests/Unit/XhttpTest.php` (6 tests): request building for `GET` (query) and
  non-`GET` (body), response rendering (status/headers/pretty JSON), help text,
  an end-to-end dispatch of a generated application route through the binary in a
  subprocess (`GET /hello/ada` -> `200`, `Hello ada!`), and the `is_dev` gate.

## Public API impact

- New class `Strukt\Framework\Console\Xhttp`.
- New binary `bin/xhttp` (dev-only). No changes to existing classes or
  interfaces.
