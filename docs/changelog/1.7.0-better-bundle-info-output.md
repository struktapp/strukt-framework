# 1.7.0 Readable bundle:info output

## What changed
- `bundle:info <name>` now prints an aligned, sectioned report:
  - `Bundle` / `Namespace` / `Published` header (plus `Requires`, `Modules`, `Files`
    when the manifest carries them),
  - a block per application type (`App:Idx`, `App:Cli`) with a count per facet and
    the classes indented underneath, `(none)` when a type contributes nothing.
- Facets are always rendered as `providers`, `middlewares`, `commands`. Previously
  `middlewares` were never printed because the loop looked up the key `middleware`
  (singular), which the manifests never use.

## Why
- The old output mixed misaligned `Type:` / `Facet:` lines, hid middlewares, and gave
  no counts, which made the command awkward to read for bundles with many commands.

## Documentation touched
- `docs/console.md` (`bundle:info` row).

## Tests added or updated
- None; `tests/Unit/ShellTest.php` covers command discovery, not this output.

## Public API impact
- Output format only; command name and argument unchanged.
