# 1.7.0 Rename package concept to bundle

## What changed
- Renamed the package system to bundles across the framework: `Strukt\Package\*` → `Strukt\Bundle\*`, `Strukt\Framework\Contract\Package*` → `Strukt\Framework\Contract\Bundle*`, `Strukt\Framework\Package\*` → `Strukt\Framework\Bundle\*`.
- Console commands: `package:*` → `bundle:*` (BundleMake/BundleAdd/BundleExport/BundleList/BundleInfo).
- Helper: `package()` → `bundle()`; `repos()` now delegates to `BundlesRepositoryInterface` and uses `list()` API.
- Configuration/discovery: `PackageRepository` → `BundlesRepositoryInterface` (via `BundleRepository`); `Repos::packages()` → `Bundles::list()`.
- Templates, commands cfg, loader template variable `{{packages}}` → `{{bundles}}`, repo.ini wording updated to bundles.
- Tests, docs, and references updated accordingly.

## Why
- Align terminology from "package" to "bundle" as specified by the rename task.

## Documentation touched
- `docs/bundles.md` (renamed from `docs/packages.md`), `docs/README.md`, `docs/console.md`, `docs/configuration.md`, `docs/helpers.md`, `docs/routing.md`, `docs/architecture.md`, `docs/dependency-injection.md`, `docs/annotations.md`, `docs/testing.md`, `docs/BACKLOG.md`, `README.md`.

## Tests added or updated
- `tests/Unit/BundleCommandTest.php` (renamed), updated ConfigTest, ConfigurationTest, ShellTest, ReloaderTest.

## Public API impact
- Breaking: `Strukt\Package\*` → `Strukt\Bundle\*`; `Strukt\Framework\Contract\Package` → `Bundle`, `PackageRepository` → `BundlesRepositoryInterface`.
- Breaking: console commands `package:*` → `bundle:*`; `package.json` concept → `bundle.json`; `package/` → `bundle/` in scaffolds; `package()` helper → `bundle()`.
- Breaking: `Strukt\Bundle\Repos::packages()` → `Strukt\Bundle\Bundles::list()`; loader template placeholder `{{packages}}` → `{{bundles}}`.
