# 1.7.0 Rename the bundles() method to list()

## What changed
- `BundlesRepositoryInterface::bundles()`, `BundlesRepository::bundles()`,
  `Strukt\Bundle\Bundles::bundles()` (static) and the test stub are now named
  `list(string $type): array`.
- All call sites updated: `Configuration::create()`, `Injectable\Configuration::getConfigs()`,
  `helpers.php` `repos()`, `BundleList`, `BundleInfo`, and `tests/Unit/ConfigTest.php`.

## Why
- Avoid the stutter of `Bundles::bundles(...)` / `$bundles->bundles(...)`;
  `list()` says what the method does (it lists bundle names for a status).

## Documentation touched
- `docs/bundles.md`, `docs/changelog/1.7.0-rename-package-to-bundle.md`.

## Tests added or updated
- `tests/Unit/ConfigTest.php`, `tests/Unit/ConfigurationTest.php` (stub).

## Public API impact
- Breaking: `bundles()` → `list()` on `BundlesRepositoryInterface`,
  `BundlesRepository`, and `Strukt\Bundle\Bundles`. Valid on PHP >= 7
  (keywords are allowed as method names).
